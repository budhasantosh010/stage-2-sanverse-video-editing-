# Stat Burst

**Canonical ID:** `sanverse.stat-burst`  
**Status:** Owner-approved default visual. Deep customization is a non-destructive override layer.

## Purpose

Reveal one large number, count or metric, then add its unit and supporting label in a second beat.

## Reusable pattern

Users · revenue · growth · speed · percentages · counts

## Visual review

Open `../../index.html` and choose **Stat Burst**, or open the viewer with `?component=stat-burst`. Compare the source principle on the left with the reusable template on the right.

## Rule

This component extracts hierarchy, choreography, pacing and spatial relationships from the reference. It does not embed the creator footage, source wording, logos or copyrighted artwork.
