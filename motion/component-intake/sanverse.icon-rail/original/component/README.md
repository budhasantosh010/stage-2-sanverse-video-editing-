# Frosted Icon Rail

**Canonical ID:** `sanverse.icon-rail`  
**Status:** Owner-approved default visual. Deep customization is a non-destructive override layer.

## Purpose

Introduce a small set of tools, brands, platforms, people or categories as a compact floating group.

## Reusable pattern

Tool stacks · platform sets · partner logos · category groups

## Visual review

Open `../../index.html` and choose **Frosted Icon Rail**, or open the viewer with `?component=icon-rail`. Compare the source principle on the left with the reusable template on the right.

## Rule

This component extracts hierarchy, choreography, pacing and spatial relationships from the reference. It does not embed the creator footage, source wording, logos or copyrighted artwork.
