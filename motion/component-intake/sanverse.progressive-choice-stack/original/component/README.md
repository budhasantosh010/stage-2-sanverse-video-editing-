# Progressive Choice Stack

**Canonical ID:** `sanverse.progressive-choice-stack`  
**Status:** Owner-approved default visual. Deep customization is a non-destructive override layer.

## Purpose

Reveal options, stages, tiers, pros/cons or states one at a time while keeping previous items visible.

## Reusable pattern

Options · steps · before/after · tiers · comparisons · status lists

## Visual review

Open `../../index.html` and choose **Progressive Choice Stack**, or open the viewer with `?component=progressive-choice-stack`. Compare the source principle on the left with the reusable template on the right.

## Rule

This component extracts hierarchy, choreography, pacing and spatial relationships from the reference. It does not embed the creator footage, source wording, logos or copyrighted artwork.
