# Milestone Brand Stage

**Canonical ID:** `sanverse.milestone-stage`  
**Status:** Owner-approved default visual. Deep customization is a non-destructive override layer.

## Purpose

Introduce a date, version, era or launch milestone, then attach a hero mark and optional related platforms.

## Reusable pattern

Timeline beats · launches · historical moments · version reveals

## Visual review

Open `../../index.html` and choose **Milestone Brand Stage**, or open the viewer with `?component=milestone-stage`. Compare the source principle on the left with the reusable template on the right.

## Rule

This component extracts hierarchy, choreography, pacing and spatial relationships from the reference. It does not embed the creator footage, source wording, logos or copyrighted artwork.
