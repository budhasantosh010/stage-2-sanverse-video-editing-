# Explainer Board

**Canonical ID:** `sanverse.explainer-board`  
**Status:** Owner-approved default visual. Deep customization is a non-destructive override layer.

## Purpose

Place a clean educational panel above or beside footage for code, passwords, diagrams, UI, rules or definitions.

## Reusable pattern

Code · UI demos · password concepts · definitions · lock/blur examples

## Visual review

Open `../../index.html` and choose **Explainer Board**, or open the viewer with `?component=explainer-board`. Compare the source principle on the left with the reusable template on the right.

## Rule

This component extracts hierarchy, choreography, pacing and spatial relationships from the reference. It does not embed the creator footage, source wording, logos or copyrighted artwork.
