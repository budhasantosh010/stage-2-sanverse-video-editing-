# Media Cutaway Stage

**Canonical ID:** `sanverse.media-cutaway`  
**Status:** Owner-approved default visual. Deep customization is a non-destructive override layer.

## Purpose

Temporarily promote an image, webpage, screenshot, document or b-roll into a clean visual evidence panel.

## Reusable pattern

Screenshots · documents · product captures · b-roll · evidence images

## Visual review

Open `../../index.html` and choose **Media Cutaway Stage**, or open the viewer with `?component=media-cutaway`. Compare the source principle on the left with the reusable template on the right.

## Rule

This component extracts hierarchy, choreography, pacing and spatial relationships from the reference. It does not embed the creator footage, source wording, logos or copyrighted artwork.
