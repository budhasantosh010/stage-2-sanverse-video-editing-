# Floating Value Cloud

**Canonical ID:** `sanverse.floating-value-cloud`  
**Status:** Owner-approved default visual. Deep customization is a non-destructive override layer.

## Purpose

Surround a subject or focal area with multiple values, prices, labels or outcomes without turning the scene into a chart.

## Reusable pattern

Costs · savings · scores · prices · outcomes · objections

## Visual review

Open `../../index.html` and choose **Floating Value Cloud**, or open the viewer with `?component=floating-value-cloud`. Compare the source principle on the left with the reusable template on the right.

## Rule

This component extracts hierarchy, choreography, pacing and spatial relationships from the reference. It does not embed the creator footage, source wording, logos or copyrighted artwork.
