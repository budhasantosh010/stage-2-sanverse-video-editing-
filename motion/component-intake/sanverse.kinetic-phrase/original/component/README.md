# Kinetic Phrase

**Canonical ID:** `sanverse.kinetic-phrase`  
**Status:** Owner-approved default visual. Deep customization is a non-destructive override layer.

## Purpose

Turn a short question, term or takeaway into a high-attention typographic beat with one controlled emphasis.

## Reusable pattern

Questions · chapter beats · definitions · punchlines · key terms

## Visual review

Open `../../index.html` and choose **Kinetic Phrase**, or open the viewer with `?component=kinetic-phrase`. Compare the source principle on the left with the reusable template on the right.

## Rule

This component extracts hierarchy, choreography, pacing and spatial relationships from the reference. It does not embed the creator footage, source wording, logos or copyrighted artwork.
