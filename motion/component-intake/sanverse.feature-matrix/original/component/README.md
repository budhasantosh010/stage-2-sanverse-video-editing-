# Feature Matrix

**Canonical ID:** `sanverse.feature-matrix`  
**Status:** Owner-approved default visual. Deep customization is a non-destructive override layer.

## Purpose

Compare a few important properties with simple pass/fail states and one larger explanatory criterion.

## Reusable pattern

Feature checks · qualification rules · product comparison · requirements

## Visual review

Open `../../index.html` and choose **Feature Matrix**, or open the viewer with `?component=feature-matrix`. Compare the source principle on the left with the reusable template on the right.

## Rule

This component extracts hierarchy, choreography, pacing and spatial relationships from the reference. It does not embed the creator footage, source wording, logos or copyrighted artwork.
