# T5.5 Timeline Visual Hierarchy

T5.5 does not redesign Studio topology.

## Creator-first hierarchy

- active tool is named in plain language (`Tool: Select`, `Tool: Razor`, `Trim · …`);
- selected item uses one semantic accent system;
- primary selected/inspected item is stronger than secondary selected items;
- selected track lane/header receive a subtle contextual highlight;
- targeting and Sync Lock stay available but are visually quieter until active, hovered or focused;
- playhead and snap guide remain above ordinary drag content;
- narrow layouts preserve active-tool information before less-critical duration text.

A consolidated T5.5 CSS confidence section uses semantic variables rather than unrelated one-off selection values.
