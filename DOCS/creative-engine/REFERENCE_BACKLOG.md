# Creative Engine Reference Backlog

Use this backlog for owner-supplied videos and visual references. A reference is evidence for reusable principles, not permission to copy a commercial design.

## Intake process

```text
OWNER REFERENCE
      ↓
frame/timestamp analysis
      ↓
classify reusable idea
      ↓
coverage audit
      ↓
existing? ─ yes → improve / variant / reuse
      │
      no
      ↓
build the smallest reusable abstraction
      ↓
record any missing Plan B / Plan C capability
```

## Entry template

```text
Reference ID:
Source:
Timestamp / region:
What owner likes:
Type: component | motion pattern | visual treatment | scene composition | editing pattern
Potential Plan: A | B | C | A+B | A+C | A+B+C
Status: unreviewed | analyzed | planned | implemented | rejected
Implementation:
Copyright/provenance note:
```
