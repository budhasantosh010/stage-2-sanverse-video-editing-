# Sanverse Creative Engine — Plan B1 Video Understanding Foundation

Date: 2026-08-10
Status: release-candidate verification in this checkpoint

## What B1 adds

B1 introduces one bounded `@sanverse/video-understanding` package. It uses the existing Sanverse exact-tick authority and provides a portable V1 source-understanding document containing source metadata, timed transcript, optional word timing, shots, temporal visual regions, normalized spatial observations, semantic moments, generic observations, confidence and provenance.

B1 remains an observation layer. It does not choose final graphics, call a vendor AI API, write CSS/DOM, mutate Motion Graph state or integrate into production `apps/web`.

## Offline analyzer

`DeterministicTranscriptSemanticAnalyzer` provides a conservative local baseline for explicit percentage, money, question, comparison, process/list, CTA, security, feature and benefit language. Analyzer interfaces remain vendor-neutral so later multimodal/language/vision analyzers can produce the same contracts.

The original generic 72-second product-launch fixture contains a 68% statistic, shared-context feature explanation, process/screen-demo section, workspace-boundary/security comparison and CTA. It commits no third-party media or branded source asset.

## B1 → B0 traceability

Creative Direction directives and proposal items now support optional stable `sourceObservationIds`. The fixture compiler preserves those references. The Creative Direction package does not import B1; it validates only bounded stable reference syntax, leaving cross-document existence checks to the integration seam.

## Development Lab

`?mode=creative-direction` now exposes Source Understanding above the existing B0 direction timeline. Five lanes are visible: SHOTS, VISUAL, TRANSCRIPT, SEMANTICS and SPATIAL. The inspector exposes the selected observation's exact time, confidence, provenance, transcript references, semantic value and spatial bounds when present.

Retained real-Edge evidence: `motion/visual-baselines/b1-source-understanding.png`. The accepted capture shows the fully loaded 72-second fixture, 68% semantic observation selected, transcript-rule provenance, transcript reference, screen-demo region, spatial lane, B0 semantic preview and typed proposal in one development screen.

## Failures found and fixed

1. The first percentage rule used a word boundary after `%`; because `%` is not a word character, `65%`/`68%` were missed. The rule was corrected instead of weakening tests.
2. TypeScript correctly refused spatial-bound indexing after an `unknown` value check in the compact validator. Bounds validation was moved behind a typed `normalizedRectValid(...)` helper.
3. The first browser screenshot captured the asynchronous loading state. It was rejected and recaptured with a bounded virtual-time wait; only the loaded state is retained as evidence.
4. During implementation, multiple same-file edits in one Harness atomic batch overwrote earlier same-file edits. Subsequent same-file changes were applied sequentially; this was a tooling workflow issue, not a B1 domain contract.

## Acceptance boundary

B1 provides source descriptor, exact ticks, transcript/word timing, shots, visual regions, normalized spatial observations, semantic moments, confidence/provenance, deterministic semantic analysis, vendor-neutral analyzers, validation, serialization, fixtures, Source Understanding Lab, observation inspector and B0 reference support without external API/model requirements or `apps/web` changes.

B2 retrieval/ranking, B3 placement, tracking/segmentation and autonomous creative direction remain unstarted.
