# Motion Originality Policy

Sanverse first-party motion graphics must be original compositions. References may be studied for general principles such as hierarchy, rhythm, timing or information structure, but commercial templates, branded compositions, distinctive animation sequences and proprietary assets may not be copied one-for-one.

Each major component/pack review records the principle extracted, the original Sanverse changes, font provenance and asset/icon provenance.

## Plan A originality/provenance review — 2026-08-08

The completed 48-component library uses Sanverse-authored component structures, responsive layouts, exact-tick motion formulas, Motion Graph scenes and style tokens. No commercial template, branded motion sequence or third-party component composition was imported into the implementation.

Reference principle used: broad motion-design principles only — hierarchy, timing, stagger, contrast, cards, lists, process diagrams, quotes and CTA composition patterns. These are generic design ideas, not copied compositions.

Original Sanverse changes: the five vertical proof components were authored against Sanverse deterministic-time constraints; the horizontal catalog was built as seven first-party family engines with distinct definitions/configurations and shared graph/exposure infrastructure rather than copied template files.

Font provenance: no font binaries are committed. Components use system/web-safe font stacks declared in style tokens (`Inter` when available, system UI fallbacks, Georgia/system serif, Consolas/system mono, Trebuchet/Segoe Print-style sketch fallback). `motion/fonts/` contains only its provenance README.

Asset/icon provenance: no third-party image/icon assets are committed for Plan A. Icons/indicators are native text glyphs, CSS geometry or authored SVG paths/shapes. `motion/assets/` contains only its provenance README.

Reference-file provenance: `motion/references/` contains only its README; no external reference media was committed as source material for the component library.

Selected browser baselines are generated evidence of Sanverse components and are not source templates.
