# Sanverse Motion Component Coverage Matrix

Date: 2026-08-08
Milestone: Plan A continuation after MOTION-C1
Baseline catalog: 48 first-party components

## Visual-review score rubric

The `Visual` column is deliberately an evidence score, not an invented aesthetic number:

- **A** — this exact component has a retained, manually inspected browser baseline from Plan A.
- **B** — the component is generated by a visually inspected family engine and passes exhaustive four-ratio/mechanical tests, but this exact variant did not have its own retained browser baseline before this inventory.

`L1 / L2 / L3 / L4` means the component has Creator, Designer, Advanced and structural Compositor readiness respectively. For the five proof components this is component-specific. For the 43 family modules, the common graph-native family contract provides the same Level 1–3 exposures and Level-4 scene structure; family tests and catalog tests verify that contract across the full generated set.

All 48 baseline components support `16:9`, `9:16`, `1:1`, `4:5` and all eight shared style packs without component duplication.

## Coverage by communication scenario

### Hooks / emphasis

Covered strongly:

- headline / statement — Kinetic Headline
- keyword emphasis — Kinetic Headline
- question — Question Title
- chapter / section — Section Title, Chapter Title, Chapter Break
- labeled takeaway — Label Title, Highlight Title

Gap worth filling now: **none**. A dedicated “contrarian statement” would mostly be copy/style variation, not a new communication primitive.

### Numbers / proof

Covered strongly:

- cost/value — Cost / Value
- growth/decline — Metric Delta
- percentage / ranking / score — Metric Delta, Score Card, Numbered List
- time/money saved — Before/After, Cost/Value
- price — Price Breakdown
- stacked numbers — Stat Stack

Gap worth filling now: **socially contextual proof** rather than another generic number card.

### Process

Covered strongly:

- checklist — Checklist
- ordered steps — Step List / Numbered List
- pipeline/workflow — Process Flow / Sequence Diagram
- funnel — Funnel Diagram
- hierarchy — Hierarchy Diagram
- flywheel — Flywheel Diagram

Gap worth filling now: none before richer timeline/roadmap semantics are justified.

### Authority / social proof

Covered:

- quote — Quote Card
- testimonial — Testimonial Card
- review/stars — Review Card
- one proof stat — Proof Stat Card

Real gaps:

- **Comment Highlight** — native social-comment communication pattern
- **Client Proof Strip** — recognizable compact client/name proof row without importing proprietary logos
- **Social Proof Stack** — several distinct proof signals combined into one hierarchy

A separate Rating/Stars Card is not selected because Review Card already owns that visual/semantic use case.

### Software

Covered:

- notification — Notification Card
- generic progress — Progress Status

Large uncovered area:

- **Browser Demo**
- **Chat Thread**
- **Dashboard Snapshot**
- **Search Results**
- **Upload Status**
- **Cursor Callout**

These are high-frequency creator/explainer graphics and fill genuinely new communication scenarios rather than restyling existing cards.

### CTA

Covered strongly:

- subscribe
- follow
- next video
- promo/resource/download-style offer
- end card

Gap worth filling now: none. A separate Download / Resource CTA would substantially overlap Promo Card.

### Explainers

Covered strongly:

- network / architecture — Team Network
- hierarchy — Hierarchy Diagram
- process/data handoff — Process / Sequence
- funnel / flywheel
- comparison — several comparison modules

Real semantic gaps selected:

- **Myth vs Fact** — explicit belief correction
- **Problem → Solution** — explicit pain-to-resolution causal framing

A generic “Quick Comparison” is not selected because Cost/Value, Before/After, Pros/Cons and Split Title already cover it.

### Editorial

Covered:

- lower third
- chapter marker
- quote card
- definition

Real gap:

- **Source / Citation Card** — visually distinct source attribution with publisher/date/URL/reference detail.

### Editing accents

Partially covered:

- badges/notifications appear inside existing modules
- highlight accents exist in title components

Real high-value gap selected:

- **Cursor Callout** — cursor/demo-specific pointing emphasis used in software explainers.

Standalone arrow/circle/divider variants are not selected in this batch because they are lower-value than missing creator communication scenarios and risk becoming decorative near-duplicates.

## Selected next batch — 12 genuinely missing scenarios

The next batch is intentionally capped at 12 and prioritized by creator/social usefulness:

1. `sanverse.comment-highlight` — social comment + handle + reaction proof
2. `sanverse.client-proof-strip` — compact client/name proof strip using original text/monogram marks, not copied commercial logos

6. `sanverse.source-citation` — publisher/date/source/URL editorial attribution
7. `sanverse.browser-demo` — browser-window explainer surface

9. `sanverse.dashboard-snapshot` — primary metric + supporting dashboard KPIs

## Duplicates explicitly avoided

The following candidate ideas were rejected because the current 48 already solve them adequately:

- Testimonial / Review Card — already both exist
- Question Card — Question Title already solves explicit question framing
- Rating / Stars Card — Review Card already includes stars/recommendation semantics
- Subscriber / Follower Milestone — generic milestone + single-metric coverage is already strong; Social Proof Stack will add the missing social context without another number-only card
- Quick Comparison — existing Cost/Value, Before/After, Pros/Cons and Split Title
- Download / Resource CTA — Promo Card already owns free-resource/download-style promotion

## Batch implementation contract

Every selected component must ship with:

- a distinct purpose and original default design,
- bounded typed content through the shared family content contract or a more specific typed contract where necessary,
- stable graph node IDs,
- Creator / Designer / Advanced exposures,
- full Motion Scene serialization/validation,
- Level-4 Layer/Node/Timeline derivability,
- generic transforms/effects/masks/blend compatibility,
- exact-tick random-access determinism,
- reduced-motion behavior,
- all four reference ratios,
- all eight style packs,
- first-class fixtures,
- focused automated tests,
- one retained real-browser visual baseline per new component, with ratios/style packs intentionally varied across the batch,
- provenance/originality notes with no copied commercial template, logo or proprietary asset.
