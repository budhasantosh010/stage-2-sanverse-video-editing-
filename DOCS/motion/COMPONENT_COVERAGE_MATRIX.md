## Visual-review score rubric

The `Visual` column is deliberately an evidence score, not an invented aesthetic number:

- **A** — this exact component has a retained, manually inspected browser baseline from Plan A.
- **B** — the component is generated by a visually inspected family engine and passes exhaustive four-ratio/mechanical tests, but this exact variant did not have its own retained browser baseline before this inventory.

`L1 / L2 / L3 / L4` means the component has Creator, Designer, Advanced and structural Compositor readiness respectively. For the five proof components this is component-specific. For the 43 family modules, the common graph-native family contract provides the same Level 1–3 exposures and Level-4 scene structure; family tests and catalog tests verify that contract across the full generated set.

All 48 baseline components support `16:9`, `9:16`, `1:1`, `4:5` and all eight shared style packs without component duplication.

## Coverage by communication scenario

### Hooks / emphasis

Covered strongly:

- headline / statement — Kinetic Headline
- keyword emphasis — Kinetic Headline
- question — Question Title
- chapter / section — Section Title, Chapter Title, Chapter Break
- labeled takeaway — Label Title, Highlight Title

Gap worth filling now: **none**. A dedicated “contrarian statement” would mostly be copy/style variation, not a new communication primitive.

### Numbers / proof

Covered strongly:

- cost/value — Cost / Value
- growth/decline — Metric Delta
- percentage / ranking / score — Metric Delta, Score Card, Numbered List
- time/money saved — Before/After, Cost/Value
- price — Price Breakdown
- stacked numbers — Stat Stack

Gap worth filling now: **socially contextual proof** rather than another generic number card.

### Process

Covered strongly:

- checklist — Checklist
- ordered steps — Step List / Numbered List
- pipeline/workflow — Process Flow / Sequence Diagram
- funnel — Funnel Diagram
- hierarchy — Hierarchy Diagram
- flywheel — Flywheel Diagram

Gap worth filling now: none before richer timeline/roadmap semantics are justified.

### Authority / social proof

Covered:

- quote — Quote Card
- testimonial — Testimonial Card
- review/stars — Review Card
- one proof stat — Proof Stat Card

Real gaps:

- **Comment Highlight** — native social-comment communication pattern
- **Client Proof Strip** — recognizable compact client/name proof row without importing proprietary logos
- **Social Proof Stack** — several distinct proof signals combined into one hierarchy

A separate Rating/Stars Card is not selected because Review Card already owns that visual/semantic use case.

### Software

Covered:

- notification — Notification Card
- generic progress — Progress Status

Large uncovered area:

- **Browser Demo**
- **Chat Thread**
- **Dashboard Snapshot**
- **Search Results**
- **Upload Status**
- **Cursor Callout**

These are high-frequency creator/explainer graphics and fill genuinely new communication scenarios rather than restyling existing cards.

### CTA

Covered strongly:

- subscribe
- follow
- next video
- promo/resource/download-style offer
- end card

Gap worth filling now: none. A separate Download / Resource CTA would substantially overlap Promo Card.

### Explainers

- funnel / flywheel

### Editorial

Covered:

- lower third

- quote card

Real gap:

### Editing accents

- **Cursor Callout** — cursor/demo-specific pointing emphasis used in software explainers.

### A18 temporal model

All nine use exact-tick C2 keyframe tracks for their authored entrance/reveal hierarchy. Common keyed properties include opacity, Y position and scale. Item/beat timing is staggered by exact ticks derived from the owning component duration. Their normal graph therefore exercises the same keyframe evaluator and Timeline projection used by compositor overrides.

Reduced motion does not freeze the beginning of the animation. For the nine A18 modules, authored motion tracks are replaced by stable final constants when `reducedMotion=true`, preserving all semantic text and useful layout.

### A18 short-form duration contract

All nine declare:

- minimum: **0.75 s**;
- default: approximately **1.8–2.4 s** depending on scenario;
- maximum: **8 s**.

Mechanical tests cover 0.75, 1, 1.5, 2, 3 and 5 seconds. Durations below 0.75 seconds and above 8 seconds fail closed during graph construction.

### A18 provenance / originality

No outside commercial template, logo, proprietary asset, screenshot or animation runtime was used to construct the nine A18 designs. They are first-party Sanverse compositions built from the existing typography, shape, graph, style-pack and C2 keyframe primitives. Default client/product names are invented or Sanverse-local. The communication principles extracted are generic: sequential emphasis, ranked choice, podium ordering, focused feature explanation and keyboard-shortcut teaching.

A18 browser evidence intentionally distributes the nine components across all eight style packs, all four reference ratios, hostile/busy backgrounds and reduced motion rather than taking 8 × 9 redundant screenshots.

### A19 authoring/data contract

A19 keeps the existing Family Creator/Designer/Advanced editing shell for title, structured rows, active item and shared style tokens, but replaces the old flat family graph with variant-specific nested scenes. Structured rows carry stable IDs such as `research`, `publish` and `lane-3-step-5`; Layer identity does not depend on array position or display text. Invalid IDs, duplicate IDs, missing references, decision/dependency cycles, invalid active IDs and excessive row density fail closed.

Every A19 component declares a **1.5–12 second** authoring window and uses the canonical Sanverse tick authority. Normal authored entrances are C2 exact-tick opacity/position/scale tracks; connector paths use exact-tick trim/reveal tracks. Reduced motion replaces those entrance tracks with final constants while preserving semantic text and hierarchy.

The bounded dense proof is a 5-lane × 5-step Swimlane: **127 graph nodes** with stable nested step IDs. It remains a single Motion Graph and projects through C3 without a second hierarchy store.
