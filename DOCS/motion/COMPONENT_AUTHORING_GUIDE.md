# Motion Component Authoring Guide

1. Define typed content and style contracts.
2. Declare purpose, category, performance class, ratios, duration bounds, events and content limits.
3. Build a strong static resting state.
4. Build landscape, portrait, square and 4:5 layouts from composition dimensions.
5. Validate and refuse impossible content instead of cropping, hiding, rewriting or shrinking essential text below its minimum.
6. Add deterministic motion from exact local ticks using shared primitives.
7. Add meaningful motion intensity and reduced motion.
8. Create min/normal/max/long/Unicode/ratio fixtures.
9. Prove direct seek, backward seek and repeated-tick determinism.
10. Render and inspect visual evidence before claiming visual completion.

Browser preview size is never layout authority. Composition width/height is layout authority.
